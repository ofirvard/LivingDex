# Living Dex

A tracker for a Pokémon living dex, including forms. It shows every Pokémon arranged in 30-slot boxes, and where each one can be obtained across all 41 core-series games.

## Run it

Double-click **`start.bat`**, or run:

```bash
python server.py
```

Then go to http://localhost:8642. Close the server window to stop the app.

### Where your progress is saved

When you start the app this way, every click is saved to **`progress.json`** in this folder. It survives restarting the app or the computer, and clearing browser data. The top bar shows **✓ Saved to file** when a save has gone through.

- The last 20 versions are kept in `backups/`, at most one per minute, in case something goes wrong.
- If you open `index.html` directly, without the server, progress is saved only in that browser, and the top bar shows a warning.
- You can also use **⋯ → Export progress** to make a manual backup file.

## Using it

- **Click** a Pokémon to mark it caught. **Right-click** it, or use the ⓘ button, to see where to get it.
- **Boxes** view lays the dex out in 30-slot boxes in dex order, so you can mirror it in Pokémon HOME. Slot labels are row-column.
- **List** view shows an availability badge for every game:
  - solid: obtainable in-game
  - striped: conditional (trade evolution, events, Friend Safari, …)
  - dashed: trade, transfer or real-life event only
- **Form toggles**:
  - Base forms: the regular form of every Pokémon. Turn it off to see only the form groups you've ticked, for example only regional forms.
  - Regional: Alolan, Galarian, Hisuian and Paldean forms
  - Variant: Unown, Vivillon, Alcremie, Meowstic/Indeedee genders, etc.
  - Gender differences: the 99 Pokémon whose females look different (e.g. Pikachu, Hippowdon), shown as ♂ / ♀
  - Changeable: Rotom, Arceus types, Therian forms, etc.

  Box numbering depends on which form types you track.
- **Catch** opens a game picker. Tick games, or whole generations, then choose:
  - **Can catch**: Pokémon you can catch in at least one of those games
  - **Can't catch**: Pokémon you can't catch in any of them

  Catching means meeting it in the wild (including DLC, Max Raid Dens and Dynamax Adventures), evolving it, or breeding it. Gifts, starters, fossils and NPC trades don't count, and neither do trade evolutions, in-game events, Friend Safari, dual-slot, or trades and transfers. Combine it with the Missing filter to see what you still need to bring in.

## Data

`data.js` is generated by `scripts/build_data.py` from the files in `source/`:

| File | From |
| --- | --- |
| `availability.wikitext` | [Bulbapedia: List of Pokémon by availability](https://bulbapedia.bulbagarden.net/wiki/List_of_Pok%C3%A9mon_by_availability) (MediaWiki API, `prop=wikitext`) |
| `pokeapi_forms.json`, `pokeapi_formsprites.json` | PokeAPI GraphQL (`pokemon_v2_pokemonform`, `pokemon_v2_pokemonformsprites`) |

To refresh, re-download those files and run:

```bash
python scripts/build_data.py
```

Bulbapedia lists some forms, like Vivillon patterns and Alcremie, under their species. Those forms are marked with `*` and use the species' availability.
